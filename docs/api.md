# API reference

Package exports first, then what createDialect returns, then its options. Full explanations live on the other pages; this is the lookup table.

## Package exports

| Export                                                       | Signature                                                                       | Description                                                                                                                                                                                                                                                                                                      |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [createDialect](#createDialect) svelte-dialect               | (options: DialectOptions) => Dialect                                            | Builds a dialect from the options below and returns the functions listed under “Returned by createDialect”. This is the entry for apps without SvelteKit.                                                                                                                                                        |
| [createDialect](#createDialect-kit) svelte-dialect/kit       | (options: DialectOptions) => Dialect                                            | The same function for SvelteKit apps. It also fills in base from paths.base and resyncs the locale after client-side navigation. Everything exported from svelte-dialect is re-exported here.                                                                                                                    |
| [Rich](#Rich) svelte-dialect                                 | <Rich parts={RichPart\[\]} {...snippets} />                                     | Renders formatParts output. MF2 markup such as {#link}…{/link} goes to the snippet of the same name; markup without a snippet still renders its contents.                                                                                                                                                        |
| [localizedEntries](#localizedEntries) svelte-dialect/entries | (paths: string\[\], { locales, defaultLocale }) => ('\*' \| \`/${string}\`)\[\] | Multiplies prerender entries across locales, base-free: SvelteKit prepends paths.base itself. This standalone version can be imported in vite.config.ts, which cannot load the dialect. createDialect returns a twin that takes only the paths and uses its own locales; it is the identity when routing is off. |

## createDialect options

| Option                                    | Default                                                       | Description                                                                                                                                                                     |
| ----------------------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [messages](#opt-messages)                 | {}                                                            | An import.meta.glob result. Eager entries are inlined; non-eager ones become per-namespace chunks. May be omitted when everything comes from loader.                            |
| [defaultLocale](#opt-defaultLocale)       | —                                                             | The locale served on the bare path and used as the ultimate fallback.                                                                                                           |
| [locales](#opt-locales)                   | from messages                                                 | Selectable locales. Defaults to those found in messages — set it explicitly when loading everything dynamically.                                                                |
| [cookie](#opt-cookie)                     | 'dialect'                                                     | A name, or { name?, maxAge?, domain?, secure? }.                                                                                                                                |
| [loader](#opt-loader)                     | —                                                             | Fetches a namespace on demand — a database call, a fetch, a remote function.                                                                                                    |
| [routing](#opt-routing)                   | false                                                         | Puts the locale in the URL as a path prefix.                                                                                                                                    |
| [base](#opt-base)                         | ''                                                            | The app's base path when served from a subdirectory. svelte-dialect/kit fills it in from paths.base; set it yourself only outside SvelteKit.                                    |
| [currentUrl](#opt-currentUrl)             | —                                                             | A reactive read of the current page URL, which resyncs the locale after client-side navigation. svelte-dialect/kit fills it in with page.url; leave it unset outside SvelteKit. |
| [detectOnBarePath](#opt-detectOnBarePath) | false                                                         | Redirects an unprefixed document visit to the visitor's own locale.                                                                                                             |
| [strategy](#opt-strategy)                 | \['url', 'cookie', 'lang', 'header', 'navigator', 'default'\] | Lookup order for the locale, first match wins.                                                                                                                                  |
| [bidiIsolation](#opt-bidiIsolation)       | false                                                         | Wraps interpolated values in Unicode bidi isolates, for RTL locales.                                                                                                            |
| [functions](#opt-functions)               | {}                                                            | Extra MF2 functions on top of the built-in set. Same name replaces one.                                                                                                         |
| [onError](#opt-onError)                   | console.warn                                                  | Receives every message error instead of the console.                                                                                                                            |
