# Security policy

## Supported versions

Only the latest published version of `svelte-dialect` receives security fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's security advisories](https://github.com/krowten/svelte-dialect/security/advisories/new)
or by email to me@krowten.dev. You'll get a reply within a few days; once a fix is out, the advisory
is published with credit to you unless you prefer otherwise.
